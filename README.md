# Godot-Realistic-TankController
A godot plugin, made speciffically for realistic tank projects. Easy to set up!
Setup Instructions;
Visit my youtube channel ; https://www.youtube.com/@GriffBolt4
OR;
1. Download the plugin from this repository
2. Unzip the downloaded plugin
3. put it in your godot's "Addons" Folder
4. Activate it by going to Project Settings > Addons
5. Create a new Scene, choose TankBody3D as the root node;
6. import your tank's 3D model, or make your own model
(NOTE: Your tank model MUST have seperate wheels in order to use the TankWheel3D)
7. Add a "TankWheel3D". as a child of your TankBody3D.
8. enter the values in TankWheel3D till it feels correct.
9. put your wheel mesh under the TankWheel3D(As its child)
10. Add a CollisionShape3D
11. Test and run it in game! (Make sure you have a floor)
12. Tweak the values till it feels correct.
